# PetData UI

Серверный HTML-браузер базы: поиск, фильтры и сортировка работают через GET-параметры, без клиентского JavaScript.

## Запуск

```bash
node ui/server.js
# http://127.0.0.1:8790/
```

Порт: `PETDATA_UI_PORT` (по умолчанию 8790).  
База: `db/petdata.db` или `PETDATA_DB`.

## Страницы

| URL | Что показывает |
|---|---|
| `/` | список SKU, поиск, фильтры, сортировка, CSV |
| `/product/:id` | карточка: нутриенты, состав, аллергены, упаковки, цены, сертификаты, источники |
| `/breeds` | породы, поиск, фильтр по виду/размеру |
| `/breed/:id` | физиология, вес, наследственные риски, гентесты |
| `/certificates` | декларации и сертификаты, фильтр по статусу |
| `/coverage` | покрытие, бренды, ошибки сбора |
| `/export.csv` | выгрузка текущего фильтра |

## Параметры списка

`q`, `species` (`cat|dog`), `brand`, `form`, `completeness`, `class` (`economy|premium|super_premium|holistic|unknown`), `me=1`, `cert=1`, `sort`, `dir`, `page`.

Сортировка: `brand`, `name`, `species`, `class`, `protein`, `fat`, `me`, `food`, `weight`, `cert`.

`food` — справочный расход корма на кг веса животного (г/кг/сут).

## Почему без JS

Предыдущая HTML-версия зависела от JavaScript, а просмотрщик его не выполнял. Здесь всё рендерится на сервере: форма поиска — обычный GET, сортировка — ссылки, пагинация — ссылки.

## Ограничения

- Нет авторизации: сервер слушает `127.0.0.1`, предназначен для локального просмотра.
- Нет редактирования: это read-only витрина.
- Для thousands SKU нужен полнотекстовый индекс (FTS уже используется) и индексы по бренду/виду.

## Доступ по сети и локальное имя

Сервер слушает все интерфейсы (0.0.0.0), поэтому база открывается с телефона
или другого устройства в той же Wi-Fi-сети. Адреса:

| Адрес | Кому подходит |
|---|---|
| http://korma:8790/ | Windows: короткое имя через LLMNR |
| http://korma.local:8790/ | iPhone/iPad, macOS, Android: имя через mDNS |
| http://192.168.2.58:8790/ | любой устройство, но IP может смениться |

Почему два имени: Windows не умеет mDNS-имена `.local`, а телефоны не понимают
LLMNR. Поэтому сервер поднимает оба ответчика — `ui/mdns.js` и `ui/llmnr.js`.

| Переменная | Значение |
|---|---|
| PETDATA_UI_HOST | 0.0.0.0 (по умолчанию) — вся сеть; 127.0.0.1 — только этот ПК |
| PETDATA_MDNS_NAME | имя в сети, по умолчанию korma |
| PETDATA_MDNS | off — не объявлять имена |

Если роутер режет multicast между клиентами (частая настройка в гостевых сетях),
имена не сработают. Запасной вариант — публичный wildcard-DNS, который превращает
IP в имя и работает на любом устройстве без настройки:

    http://192-168-2-58.nip.io:8790/   (тот же 192.168.2.58)

Авторизации нет: базу увидит любое устройство в сети.
