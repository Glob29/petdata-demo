# Агент сбора кормов

Агент собирает карточки кормов с сайтов производителей, извлекает состав и нутриенты, нормализует и загружает в `petdata.db`. Работает без внешних зависимостей на Node.js 22.5+.

---

## Запуск

```bash
node agent/collect.js     # сбор по brands.json
node db/normalize.js      # очистка имён, дедупликация, FTS
node db/classify.js       # эконом / премиум / супер-премиум / холистик
node db/compute-feeding.js # расход г/кг/сут
node agent/eval.js        # проверка на gold set
node agent/inspect.js     # что загружено
node agent/export-html.js # автономный HTML-отчёт → report/index.html
```

Настройки:

- `agent/brands.json` — бренды, сайты, URL каталогов, лимиты;
- `PETDATA_DB` — путь к SQLite-базе;
- `agent/cache/` — кэш HTML (12 часов);
- `agent/report.json` — отчёт последнего запуска.

---

## Как работает

```
brands.json
   ↓
discover: sitemap или ссылки с категорий
   ↓
http: fetch + кэш + задержка + User-Agent
   ↓
extract: JSON-LD + регулярки (состав, белки, жиры, клетчатка, зола, влага, ME)
   ↓
normalize: единицы, вид, форма, вес, аллергены
   ↓
load: product, package, product_nutrient, ingredient, product_protein_source
   ↓
FTS5-индекс product_fts
   ↓
report.json + extraction_run
```

---

## Что извлекается

- название, GTIN (если есть в JSON-LD), вид, форма, полнорационность;
- вес упаковки из названия/URL/страницы; если карточка перечисляет несколько фасовок
  («ДОСТУПНЫЕ ВЕСОВКИ 400g, 1.5kg, 3kg»), сохраняются все — по строке `package` на каждую;
- цены по фасовкам из блока «Вес упаковки» (₽/кг для каждого варианта) — см. `agent/lib/offers.js`;
- состав (эвристика по «Состав» + проверка на ингредиентные слова);
- белок, жир, клетчатка, зола, влага, ME;
- ингредиенты с процентами и аллергенными группами;
- источники белка: курица, индейка, утка, говядина, баранина, свинина, кролик, рыба, молоко, яйцо, злаки;
- ссылки на сертификаты/декларации, если они есть на странице.

## Сбор цен

`node agent/collect-prices.js --all --apply` — добирает цены по фасовкам с 4lapy:

1. товарные URL берутся из sitemap (фильтр `?brand=` на сайте не работает на сервере);
2. из карточки читается `__NEXT_DATA__` — для каждой фасовки вес (`weightInGrams`) и цена (`priceValue`);
3. SKU сопоставляется по названию, виду и форме; записываются только совпавшие по весу фасовки;
4. отчёт по всем кандидатам — `agent/price-matches.json` (там видно, что принято, а что нет).

Второй источник — `agent/collect-prices-magizoo.js`: у magizoo каталог и бренд-страницы
отдаются серверным HTML, а цена и вес берутся из JSON-LD карточки.

Проверенные и отброшенные источники: **onlinetrade.ru** — капча (поворот картинки), headless-браузер
её не проходит; **petshop.ru** — карточки серверные, но каталог и бренд-страницы рендерятся JS,
а в sitemap бренда в слаге нет.

## «Обучение» и проверка

Модель не обучается: качество держится на правилах и gold set.

`agent/gold.json` — 4 эталонные карточки с ожидаемыми значениями.  
`agent/eval.js` сравнивает извлечение с эталоном и считает точность.

Текущий результат: **23/23 проверки, 100%**. При изменении вёрстки или добавлении бренда gold set нужно расширять.

## Сертификаты: что выяснилось

Агент проверил карточки товаров и страницы качества:

- Whiskas — документов нет;
- Grandorf — документов нет;
- Hill's — есть страница «Качество и безопасность», но без деклараций/сертификатов.

Это ожидаемо: с 01.09.2025 корма декларируются по ГОСТ Р 55453-2022, но сами декларации публикуются в реестре Росаккредитации (`pub.fsa.gov.ru`), а не на сайтах брендов. Ветеринарные сертификаты — для партий/ввоза, не для каждой карточки.

Следующий шаг — интеграция с реестром ФСА. Для этого нужен доступ к API/токену или ручная загрузка номеров деклараций.

## Ограничения

- Нет headless-браузера: страницы, которые рисуют данные через JS, не собираются.
- Royal Canin не включён: его каталог отдаёт товары через Nuxt/API, нужен отдельный адаптер.
- Hill's страницы могут отдавать разные веса упаковки; вес берётся первый найденный.
- `completeness` у части SKU = `unknown`: на странице нет слова «полнорационный».
- Certificates: только открытые ссылки; реестр ФСА не подключён.
- Нет цен: для цен нужен отдельный агент по ритейлерам.

## Как добавить бренд

1. Добавить объект в `agent/brands.json`:

```json
{
  "brand": "Purina One",
  "manufacturer": "Nestlé Purina",
  "site": "https://purina.ru",
  "source_name": "Purina One RU",
  "certificate_pages": ["https://purina.ru/"],
  "discovery": {
    "type": "links",
    "urls": ["https://purina.ru/brands/purina-one"],
    "pattern": "/products/",
    "min_segments": 3
  },
  "max_products": 6
}
```

2. Проверить, что ссылки на карточки действительно попадают в `pattern`.
3. Запустить `node agent/collect.js`.
4. Посмотреть `agent/report.json` и `node agent/inspect.js`.
5. Добавить 1–2 карточки в `gold.json` и проверить `eval.js`.
