# Породы: откуда данные и насколько им можно верить

Breed DB в демо — 30 пород: 19 собак и 11 кошек, 108 предрасположенностей и 17 генетических тестов.

Задача этого документа — честно разделить «проверено по стандарту» и «экспертная оценка»,
чтобы при продаже данных не выдавать второе за первое.

---

## Пайплайн

```
ru.wikipedia (инфобокс, параметры FCI)
        │  node agent/fetch-breeds.js
        ▼
agent/cache/wiki/*.txt          сырой wikitext, 24 страницы + index.json
        │  ручная курация: сверка роста/веса/жизни, добавление рисков и гентестов
        ▼
db/breeds-data.json             единственный источник правды
        │  node db/gen-breeds-sql.js
        ▼
db/seed-breeds.sql              генерируется, вручную не править
        │  node db/import.js   (чистая сборка)
        │  node db/migrate-breeds.js  (накат на живую базу, идемпотентно)
        ▼
SQLite: breed / breed_weight / breed_predisposition / condition / genetic_test
        │  node db/check-breeds.js
        ▼
отчёт о целостности (код возврата 1 — не катить)
```

`db/breeds-data.json` — то, что редактируется. Всё остальное — производное.
`on conflict(id) do update` в сгенерированном SQL означает: поправили JSON → перегенерировали →
накатили, и карточка обновилась, а SKU и остальные таблицы не тронуты.

первичный стандарт находится за один шаг.

## Что проверено, а что оценка

`breed.extra_json.data_quality`:

- `fci` — 11 пород: рост/вес/жизнь взяты из инфобокса, значения соответствуют стандарту FCI;
- `mixed` — 4 породы: часть полей из инфобокса, часть — экспертная оценка (в `extra_json` нет пометки,
  но расхождение видно по `note` в карточке; список ниже);
- `estimate` — 9 пород: открытого структурированного источника не нашлось.

| Порода | quality | Что именно оценка |
|---|---|---|
| Йоркширский терьер | mixed | продолжительность жизни 13–16 (в карточке ru.wiki 16–18) |
| Чихуахуа | estimate | рост 15–23 см: стандарт FCI рост не задаёт |
| Мопс | mixed | рост 28–32 см: стандарт FCI рост не ограничивает |
| Померанский шпиц | estimate | вес 1,8–3,5 кг |
| Золотистый ретривер | estimate | рост и вес: в инфобоксе их нет |
| Английский кокер-спаниель | mixed | продолжительность жизни 11–14 лет |
| Боксёр | mixed | вес кобелей 30–32 кг, сук 25–27 кг (в инфобоксе «от 30 кг» / «25 кг») |
| Бордер-колли | estimate | рост 48–56 см (в инфобоксе пусто) |
| Бенгальская кошка | estimate | вес 3,5–7 кг, продолжительность жизни 12–16 лет |
| Канадский сфинкс | estimate | вес 3,5–5,5 кг |
| Русская голубая | estimate | вес 3–5 кг, продолжительность жизни 15–20 лет |
| Сиамская кошка | estimate | вес 3–5 кг, продолжительность жизни 15–20 лет |
| Ориентальная кошка | estimate | вес 3–5 кг |

У кошек фелинологические стандарты (FCI, WCF, TICA) вес не нормируют — поэтому для них
вес почти всегда оценка. Это ограничение источника, а не лень.

## Уровни доказательности предрасположенностей

- **A** — связь с конкретной мутацией или породообразующим признаком, есть гентест или
  устойчивое воспроизведение в исследованиях (например, IVDD у таксы, ARVC у боксёра,
  остеохондродисплазия у шотландской вислоухой).
- **B** — породная предрасположенность описана в ветеринарных выборках (VetCompass, Agria).
- **C** — встречается в литературе и практике, но выборки слабее.
- **D** — единичные сообщения. В демо не используется.

Уровень — это оценка силы связи, а не гарантия для конкретного животного. Формулировки в
`prevalence_text` намеренно не количественные: «повышенный риск», а не «в 3,2 раза».

## Что нужно сделать до продажи

1. Сверить 9 полей `estimate` с первичными стандартами FCI/WCF и заменить `source_id = 19`
   на конкретный документ.
2. Для уровней A и B поднять первичные публикации (VetCompass breed reports, OMIA-записи)
   и сохранить их как отдельные `source` с прямой ссылкой.
3. Добавить породные выборки по РФ: частота встречаемости в российских клиниках отличается
   от британских данных VetCompass.
4. Заполнить `breed_weight` для щенков и котят — сейчас только взрослые.

## Как добавить породу

1. Добавить страницу в `TITLES` в `agent/fetch-breeds.js`, запустить — появится кэш.
2. Внести запись в `db/breeds-data.json` (id следующий свободный, `predispositions` — только
   те, для которых есть основание).
3. `node db/gen-breeds-sql.js` → `node db/migrate-breeds.js` → `node api/test.js`.
4. Обновить счётчики в `api/test.js` и README, если изменилось число пород.
