# Аллергены и источники белка

**Дата:** 21.11.2026  
**Задача:** добавить в базу не только нутриенты, но и источники животного/растительного белка, чтобы фильтровать корма при аллергии.

---

## 1. Зачем это нужно

Если у собаки аллергия на курицу, недостаточно хранить «белок 27%». Нужно знать:

- какое именно животное или растение является источником белка;
- указан ли вид или только «птица»/«мясо»;
- есть ли гидролизованный белок;
- какие группы риска и перекрёстные реакции.

Без этого приложение не сможет ответить на простой запрос: «покажи корма без курицы».

---

## 2. Что говорит наука

### 2.1 Частые аллергены

По обзору [Olivry, Mueller, Prelaud (CAT 2)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4710035/):

- **Собаки:** говядина, молочные продукты, курица, пшеница, баранина.
- **Кошки:** говядина, рыба, курица.

Порядок может отличаться по регионам, но эти источники — основные.

### 2.2 Перекрёстная реактивность

- **Птица:** курица, утка и индейка сильно перекрёстно реагируют. В исследовании IgE-реактивность к курице была у 100% собак, к утке и индейке — у 97%. Поэтому «индейка вместо курицы» — не безопасная замена при подтверждённой аллергии ([исследование](https://europepmc.org/article/pmc/5561598)).
- **Млекопитающие:** говядина, баранина и молоко имеют общие эпитопы; оленина не всегда является «новым» белком ([серологическое исследование](https://www.sciencedirect.com/science/article/abs/pii/S1041782617300920)).
- **Рыба:** парвальбумин — общий аллерген, перекрёстная реактивность между видами рыбы.
- **Растительные белки:** соя, пшеница, кукуруза, бобовые — отдельные группы.

### 2.3 Контаминация

ELISA-исследование коммерческих сухих кормов показало наличие сои и говядины там, где их не должно быть по составу — вероятно, из-за перекрёстной контаминации на производстве ([Wiley 2010](https://onlinelibrary.wiley.com/doi/full/10.1111/j.1439-0396.2010.01016.x)).

Вывод: **«без курицы» на упаковке — не гарантия отсутствия следов**. В базе нужен флаг `may_contain`.

## 3. Таксономия

### 3.1 Группы

| Код | Название | Источники | Перекрёстная реактивность |
|---|---|---|---|
| `poultry` | Птица | курица, индейка, утка, перепёл | Высокая внутри группы |
| `mammalian` | Мясо млекопитающих | говядина, баранина, свинина, оленина | Говядина/баранина/молоко; оленина — возможно |
| `dairy` | Молочные продукты | молоко, сыворотка, казеин | С говядиной |
| `fish` | Рыба | лосось, треска, белая рыба, сельдь | Парвальбумин, между видами |
| `egg` | Яйцо | куриное яйцо | — |
| `wheat` | Пшеница/глютен | пшеница, ячмень, рожь | — |
| `soy` | Соя | соевый белок, изолят | — |
| `corn` | Кукуруза | кукуруза, глютен | — |
| `rice` | Рис | рис, рисовый белок | — |
| `legumes` | Бобовые | горох, чечевица, нут | — |
| `plant_other` | Растительный белок без уточнения | изолят | Нельзя исключить сою/горох |

### 3.2 Источники

В базе 19 источников: chicken, turkey, duck, beef, lamb, pork, venison, salmon, whitefish, dairy, egg, wheat, soy, corn, rice, legumes, plant_unspecified, poultry_unspecified, turkey_hydrolyzed.

`poultry_unspecified` — важный случай: производитель пишет «белок птицы», не указывая вид. Для аллергии это **небезопасно**, поэтому такие продукты попадают в `may_contain: poultry`.

## 4. Поля в базе

```
allergen_group
  code, name_ru, cross_reactivity_note

protein_source
  code, name_ru, group_code, animal_origin, is_novel

product_protein_source
  product_id, protein_source_id, role,
  declared_percent, is_hydrolyzed, confidence
```

`product_quality` хранит текстовый `protein_source` и флаги, но для фильтрации используется `product_protein_source`.

## 5. API

### 5.1 Карточка продукта

```json
"allergens": {
  "contains": ["chicken"],
  "groups": ["poultry"],
  "may_contain": [],
  "hydrolyzed_components": false,
  "sources": [
    { "code": "chicken", "name": "Курица", "group": "poultry", "declared_percent": 60 }
  ],
  "cross_reactivity": ["Высокая перекрёстная реактивность: курица/утка/индейка..."]
}
```

### 5.2 Фильтры

| Параметр | Пример | Логика |
|---|---|---|
| `exclude_allergen` | `chicken` | Исключает курицу **и всю группу poultry** (консервативно) |
| `exclude_allergen` | `beef` | Исключает говядину и группу mammalian |
| `protein_source` | `turkey` | Только продукты с индейкой (точное совпадение) |
| `protein_source` | `poultry` | Все продукты с птицей |
| `hydrolyzed` | `true` | Есть гидролизованный компонент (не значит «полностью гидролизованная диета») |

**Важно:** `exclude_allergen=chicken` исключает индейку и утку. Это сделано намеренно, потому что перекрёстная реактивность высокая. Если нужен строгий фильтр только по курице — это отдельный параметр в будущем.

### 5.3 Справочник

`GET /v1/allergens` — группы и источники с перекрёстными реакциями.

## 7. Ограничения

- Состав на упаковке часто неполный: «мясо», «птица», «рыба» без вида.
- «Без курицы» не гарантирует отсутствие следов из-за контаминации.
- Гидролизованный белок не всегда полностью гипоаллергенен; степень гидролиза важна.
- Аллергия — диагноз ветеринара, а не фильтр в приложении. База помогает **сузить выбор**, но не заменяет элиминационную диету.
- Мы не делаем лабораторных тестов: опираемся на опубликованные данные и состав.
