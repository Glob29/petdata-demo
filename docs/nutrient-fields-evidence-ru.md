# Какие поля нужны базе: доказательная база

**Дата:** 21.11.2026  
**Задача:** отобрать не «все возможные» нутриенты, а те, что реально влияют на здоровье собак и кошек, и отделить их от маркетинговых ингредиентов.

---

## 1. Главный принцип: нутриенты, а не ингредиенты

WSAVA Global Nutrition Committee прямо указывает: список ингредиентов говорит о том, **что** положили в корм, но не о качестве и количестве нутриентов. Оценивать рацион нужно по нутриентному профилю, а не по наличию «полезной» ягоды или «суперфуда» в составе.

Поэтому в базе:

- **поля** — нутриенты и измеримые показатели качества;
- **ингредиенты** — отдельная таблица для состава, процентов и аллергенов;
- **маркетинговые заявления** — только свободный текст `claims`, без превращения в поля.

## 3. Обязательные поля (ядро)

Это нутриенты, для которых есть установленная потребность или которые участвуют в ключевых функциях. Список соответствует таблице NRC 2006 в обзоре Blanchard et al.

### 3.1 Энергия и макронутриенты

| Поле | Единица | Зачем |
|---|---|---|
| `me` | ккал/кг | Расчёт порции; без ME нельзя сравнить корма |
| `protein` | % | Сырой протеин; минимум, но не качество |
| `fat` | % | Энергия, незаменимые жирные кислоты |
| `fiber` | % | ЖКТ, насыщение, плотность энергии |
| `ash` | % | Минеральная нагрузка, косвенный показатель качества |
| `moisture` | % | Пересчёт на сухое вещество |
| `carbs_nfe` | % | Расчёт по разности; не потребность, но важный фактор |

## 4. Показатели качества (не «нутриенты», но нужны)

Именно они превращают базу из «таблицы процентов» в продукт, по которому можно сравнивать корма.

| Поле | Что показывает | Как получать |
|---|---|---|
| `protein_source` | Названные источники животного белка | Из состава |
| `animal_protein_percent` | Доля животного сырья | Из процентов на упаковке |
| `protein_digestibility_pct` | Усвояемость белка | Публикации/производитель; цель ≥80% |
| `diaas` | Digestible Indispensable Amino Acid Score | Расчёт по опубликованным данным |
| `protein_quality_score` | Экспертная 0–5 | Рубрика: прозрачность + источник + усвояемость |
| `omega6_omega3_ratio` | Баланс жирных кислот | Расчёт |
| `carbs_dm_percent` | Углеводная нагрузка | Расчёт на DM |
| `fiber_type` | Растворимая/нерастворимая | Из источника клетчатки |
| `ingredient_flags` | `named_meat_first`, `plant_protein`, `by_products` | Из состава |

**Важно:** `protein_quality_score` — экспертная оценка, а не лабораторный показатель. В API её нужно помечать как `quality` с `method: expert_rubric`.

---

## 5. Что не превращаем в поля

Маркетинговые ингредиенты не должны становиться отдельными нутриентными полями. Их место — `claims` и `ingredients`:

- ягоды, гранат, клюква, черника;
- юкка, водоросли, «суперфуды»;
- «иммунитет», «шерсть и кожа», «суставы» — это следствия витаминов, цинка, омега-3, глюкозамина, а не отдельные нутриенты;
- глюкозамин/хондроитин — допустимы как `optional` для ветеринарных/суставных продуктов, но не как ядро;
- L-карнитин, бета-каротин — опционально;
- «пребиотики» — это клетчатка/олигосахариды, а не отдельный нутриент.

Если производитель заявляет «содержит гранат», это не значит, что гранат влияет на здоровье в количествах, присутствующих в корме. В базе это `claim`, а не поле.

## 6. Валидация: что проверять автоматически

Для взрослых собак AAFCO (через German et al., 2025) на 1000 ккал:

| Показатель | Диапазон |
|---|---|
| Белок | ≥ 45 г |
| Жир | ≥ 13,8 г |
| Кальций | 1,25–6,25 г |
| Фосфор | 1,0–4,0 г |
| Ca:P | 1:1–2:1 |
| Калий | ≥ 1,5 г |
| Натрий | ≥ 0,2 г |
| Магний | ≥ 0,15 г |
| Железо | ≥ 10 мг |
| Медь | ≥ 1,83 мг |
| Марганец | ≥ 1,25 мг |
| Цинк | ≥ 20 мг |

Проверки в БД:

- сумма белка, жира, клетчатки, золы и влаги: 95–100%;
- углеводы не отрицательные;
- ME по modified Atwater: 3,5×белок + 8,5×жир + 3,5×углеводы;
- расхождение с заявленной ME ≤15–20%;
- Ca:P 1–2;
- для кошек: таурин, арахидоновая, витамин A;
- флаги, если производитель не указал влагу, ME, витамины.

## 7. Итог: сколько полей нужно

- **~40–45 обязательных** нутриентов (макро, аминокислоты, жирные кислоты, минералы, витамины).
- **~8–10 показателей качества** (белок, жир, углеводы, клетчатка, флаги).
- **~5 опциональных** (глюкозамин, хондроитин, L-карнитин, бета-каротин, кобальт).

Этого достаточно, чтобы описывать любой корм и сравнивать бренды. Дальше расширять список «экзотическими» нутриентами не нужно — это увеличит стоимость сбора, но не ценность для 95% пользователей.

---

## 8. Что уточнить у ветеринарного нутрициолога

1. Нужен ли `protein_digestibility_pct` как обязательное поле или достаточно флага «не заявлено».
2. Порог `protein_quality_score` и правила рубрики.
3. Для кошек: минимальный набор аминокислот, который реально проверять.
4. Для пожилых/хронических болезней: какие поля критичны (P, Na, K, omega-3, белок).
5. Нужно ли хранить `urine pH` и `taurine` отдельно для ветеринарных диет.
