**Дата снимка:** 21.11.2026  
**Рынок:** Россия, розничные цены  
**Цель:** проверить, что выбранные поля собираются, считаются и дают осмысленное сравнение.

## 3. Что видно

### 3.1 Цена за килограмм обманчива

Разброс цены за кг — **1,46–2,05 тыс. ₽** (в 1,4 раза).  
Разброс цены за **100 г белка** — **364–693 ₽** (в 1,9 раза).  
Разброс цены за **100 ккал** — **38–50 ₽** (в 1,3 раза).

Вывод: сравнивать корма по цене за кг недостаточно. Энергетическая плотность и содержание белка меняют картину. Для базы нужны вычисляемые метрики, а не только цена упаковки.

### 3.2 «Больше белка» не значит «дороже»

- Purina: 41% белка, самая низкая цена за 100 г белка (364 ₽), но ME не заявлена и есть растительные белки.
- Grandorf: 37% белка, 457–553 ₽ за 100 г белка, прозрачные источники (32% дегидрированной индейки + 29% свежей + 5% гидролизата).
- Royal Canin: 27% белка, 539–693 ₽ за 100 г белка — самый дорогой белок в тройке, при этом растительные белки (пшеничный глютен, кукуруза) в составе.

### 3.3 Полнота данных — главный вывод

| Поле | Заполнено |
|---|---|
| Цена | 3/3 |
| Белок, жир, клетчатка, зола | 3/3 |
| ME | 2/3 |
| Влага | 0/3 |
| Витамины | 0/3 |
| Минералы | 0/3 |
| Аминокислоты | 0/3 |
| Усвояемость белка / DIAAS | 0/3 |

Это не ошибка демо, а реальность рынка: **макронутриенты и цена доступны, микронутриенты — почти нет**. Поэтому база должна:

- хранить `min/max/typical` и `confidence`;
- явно показывать `missing` (как `note: moisture_missing`);
- не строить «полноценность рациона» на пустых полях;
- добирать микронутриенты из опубликованных исследований и официальных фидов.

## 4. Проверка механики

Что сработало в API:

- `price_snapshot` хранит несколько цен на товар;
- `product_metrics` считает цену за кг, 100 г, 100 г белка и 100 ккал;
- `product_quality` хранит источник белка, долю животного сырья, оценку и флаги;
- `product_nutrient` хранит базис и уверенность;
- пересчёт as-fed → DM работает.

Пример ответа:

```json
{
  "brand": "Royal Canin",
  "name": "Indoor 27",
  "metrics": {
    "weight_g": 2000,
    "price_per_100g_protein": { "min": 539.07, "max": 693.33 },
    "price_per_100kcal": { "min": 38.15, "max": 49.07 },
    "protein_g_per_1000kcal": 70.8
  },
  "quality": {
    "protein_quality_score": 2.5,
    "flags": ["plant_protein", "low_protein", "opaque_animal_share"]
  }
}
```

## 5. Ограничения проверки

- Цены розничные и меняются; нужен регулярный снимок.
- Значения белка/жира — с карточек, не лабораторные.
- ME у Purina не заявлена; расчёт по Atwater без влаги даст большую погрешность.
- `protein_quality_score` — экспертная рубрика, не лабораторный показатель.
- Нет проверки витаминов, минералов, аминокислот — их в открытых карточках нет.

## 6. Следующий шаг

1. Довести gold set до **50 SKU**: 5 брендов × 10 продуктов.
2. Сверить значения с опубликованными исследованиями и официальными профилями FEDIAF/AAFCO — **без лаборатории**.
3. Заполнить аллергены и источники белка по составу, проверить `poultry_unspecified`.
4. Добавить 3–5 брендов: Hill's, Farmina, Monge, Brit.
5. После этого фиксировать поля и запускать API-пилот.
